# Streamlit UI Usage Guide (Wave 4 RC)

## Query Flow
1. Enter query text and choose top-k.
2. Optionally set strategy/source/date filters.
3. Submit query and inspect ranked results with provenance.

## Validation Utilities
- Query history is captured for current session.
- Response payload can be exported for debugging.
- Relevance feedback can be recorded per result.
